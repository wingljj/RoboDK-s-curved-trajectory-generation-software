# 软件品牌与安装交付 — 0.1.2

产品名称为“上海卫星装备研究所曲面轨迹生成软件”；研发单位为“上海卫星装备研究所”，
研发部门为“总装中心”。沿用用户提供的中国航天标志原图。

主窗口标题、打开模型后的标题、应用图标和 Windows 可执行文件版本信息使用统一品牌。
“帮助 → 关于”介绍 STEP/STP 导入、CAD 曲面选择、B-Rep 曲面路径生成、法向和 TCP 姿态、
参数调整与三维预览、连续 CSV 导出，并提供版本和研发信息。

Inno Setup 安装包使用品牌图标与航天蓝向导侧栏，提供中文软件介绍、开始菜单快捷方式、
可选桌面快捷方式和品牌卸载入口。安装到当前用户的程序目录，包含运行所需 Qt 和 MSVC DLL、
STEP 示例、使用说明及第三方许可。技术内部项目和可执行文件名保持 SurfacePathStudio，
以便已有脚本和构建工具继续使用。

验收覆盖 Qt 5/6 构建、既有 42 项 CTest、实际“关于”菜单打开/关闭与图标加载、
模型导入后的标题、连续轨迹桌面流程，以及安装后独立启动、品牌登记和卸载清理。
