# CAD examples

The seven files in `models/` are genuine STEP B-Rep models generated by the C++
Open CASCADE fixture library. They retain analytic or B-Spline surfaces, trims,
and topological wires. No triangulation is used to construct the models.

| File | Geometry | Suggested direction | Reference normal |
| --- | --- | --- | --- |
| `plane.step` | 100 x 80 mm rectangle | +X | Automatic (+Z) |
| `cylinder.step` | R30 mm cylindrical patch, height 80 mm | +Z | +X |
| `cylinder_full.step` | Complete R30 mm cylindrical side face, height 80 mm | +Z | +X, required |
| `sphere_trimmed.step` | R60 mm sphere trimmed to an equatorial patch | +Z | +X |
| `bspline_trimmed.step` | An undulating interpolated B-Spline with trimmed boundaries | +X | Automatic |
| `adjacent_bspline.step` | Two patches of the same B-Spline sharing a sewn Edge | +X | Automatic |
| `inner_hole.step` | 100 x 80 mm rectangle with R12 mm hole at (50, 40, 0) | +X | Automatic (+Z) |

The application’s example menu loads the fixture’s suggested parameters. For a
STEP file opened manually, set the direction and reference normal shown above.
The full cylinder has no unique average surface normal, so it needs an explicit
reference normal to define the section frame.

Start with a 10 mm step over and a 2 mm point distance. The flat rectangle should
produce nine process rows, including its outer boundaries. Rows crossing the
hole should split into separate process segments. Paths on the B-Spline should
follow the real CAD surface; its internal seam should retain continuous paths.

To regenerate the STEP files after building, run from the project directory:

```powershell
& '.\build\native-release\tests\surfacepath_generate_examples.exe' '.\examples\models'
```

The generator writes millimetres explicitly. Automated tests also write an inch
STEP, read it into the millimetre XCAF document, and check that the same rectangle
still measures 100 x 80 mm. A separate nested assembly test checks names, colors,
instance placement, and Face ID lookup after STEP transfer.
